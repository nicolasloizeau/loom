# Weaving: project summary

**What it is.** A generative art project that creates images of woven
cloth. A grid decides, at every point where two threads cross, whether the
horizontal or the vertical thread is on top. Change the grid and you change
the weave. The thread colours repeat as simple stripes in each direction.

**Where the patterns come from.** Cellular automata: simple rules that grow
complex structure from a tiny start. One-dimensional rules give maze-like
and lace-like textures. Two-dimensional rules, grown outward from a single
point, give symmetric medallions that recall rugs and tiles. Smoother
"random noise" patterns were tried and set aside.

**How it looks.** Each pattern is shown as if photographed as real cloth:
soft round threads with a visible twist, stray fibres giving a fuzzy halo,
loose frayed ends at the edges, a gently uneven hand-made feel, soft angled
light, film grain, on a dark charcoal background.

**Format.** Square by default (1350 x 1350), about 48 threads across; other shapes, such as Instagram portrait (4:5, 1080 x 1350), are a setting.

**Status.** A shortlist of 14 favourite patterns is rendered, each with
variations (different starting points, bigger threads). Current work:
colour palettes, each split into one family of colours for the horizontal
threads and a contrasting one for the vertical threads.

**Keywords.** Textile, handmade, tactile, mathematical, generative, rules
and emergence, colour.
